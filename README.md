## 🚀 About the Project

**COA Von Neumann & Cache Architecture Studio** is an interactive educational web application designed to simplify complex concepts in Computer Organization and Architecture (COA).

The platform allows students to visualize CPU instruction execution, experiment with different addressing modes, and understand cache memory operations through real-time simulations.

Instead of just studying theoretical concepts, students can interact with a virtual computer system and observe how instructions, registers, memory, and cache work together.

## ✨ Key Features

### 1. 🧠 Von Neumann CPU Cycle Simulator
Explore the internal working of a basic CPU through the Fetch–Decode–Execute cycle.

- Simulates LOAD, ADD, and STORE instructions.
- Visualizes CPU registers: PC, MAR, MDR, IR, and AC.
- Displays 16 × 16-bit main memory.
- Supports step-by-step clock cycle execution (T1–T6).
- Provides instruction execution logs and register updates.
- Interactive instruction prediction with XP rewards.

### 2. 🔢 Addressing Modes Evaluator
Understand how the CPU locates operands using different addressing techniques.

Supports five addressing modes:

- Immediate Addressing
- Direct Addressing
- Indirect Addressing
- Register Addressing
- Indexed Addressing

**Interactive functionality:**
- Enter custom address fields.
- Modify register R1 values.
- Calculate Effective Addresses (EA).
- View operand values and memory access counts.
- Understand how each addressing mode works.

### 3. ⚡ Direct-Mapped Cache Simulator
Explore how cache memory improves data access performance.

- Simulates a 4-line direct-mapped cache.
- Supports 16 main memory blocks.
- Calculates cache index and tag.
- Identifies Cache HIT and Cache MISS.
- Demonstrates compulsory, conflict, and capacity misses.
- Displays block replacement and eviction.
- Calculates Hit Ratio and Average Memory Access Time (AMAT).
- Includes a predefined cache benchmark sequence.

## 🎮 Interactive Learning Experience

The application includes a gamified learning experience to make computer architecture concepts more engaging.

- Earn Architecture XP points.

## ▶️ How to Run the Project

Getting started is simple. No complicated installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` or open it using your web browser.
5. Start exploring the three interactive simulation modules.

```bash
git clone YOUR_REPOSITORY_URL
```

Open `index.html` in Chrome, Edge, or Firefox.
